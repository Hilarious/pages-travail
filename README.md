# Pages de travail

Hébergement des outils et des livrables consultables d'un compte client.

## Comment publier une page

1. Fabriquer la page avec l'outil, ce qui produit un fichier `.html`
2. Sur ce dépôt, bouton **Add file**, puis **Upload files**
3. Déposer le fichier dans le dossier de la Wave, sous le nom `index.html`
4. Écrire une ligne de description et valider

Le site se redéploie tout seul. L'adresse ne change pas.

## Règles

- **Chaque dossier porte un suffixe aléatoire.** C'est ce qui rend son adresse non devinable.
  Ne jamais renommer un dossier en une forme prévisible, et ne jamais lister les adresses ailleurs
  que dans le dossier du compte.
- **Rien n'est indexé.** `robots.txt` interdit tout, et chaque page porte une balise `noindex`.
- ⚠️ **Ce n'est pas une protection.** Qui possède l'adresse accède à la page. Ne rien déposer ici
  qui ne puisse pas fuiter : pas de contrat, pas de tarif, pas de donnée personnelle.
- La racine du site ne dit rien et ne liste rien. C'est volontaire.
